Open Aria Echo · App 端 v3：标准手机相机布局

三层结构，上下分工

  • 顶栏 58：左边机身状态胶囊，右边四个图标开关（网格、对焦峰值、IMU、设置）。
  • 取景窗 520：只放画面与网格，除了录制计时外不压任何控件。
  • 底部黑色操作区 266：变焦胶囊 → 状态行 → 模式条 → 快门行，四行固定顺序。

快门行

  • 中间 82pt 大快门：空闲红圆、录制中红方、不可用变暗。
  • 左侧 52pt 会话缩略图，右侧 52pt 切换机身，与相机的相册 / 翻转位置一致。

与 v2 的区别

  • 去掉悬浮在画面右侧的工具列，全部上提到顶栏。
  • 去掉渐变遮罩，底部改为实心黑色操作区，控件不再压在画面上。
  • 预览不再充满屏幕，固定为 3:4 取景窗，上下黑边是结构的一部分。
  • 快门加大到 82pt，左右两个副按钮缩到 52pt，主次拉开。

保留不变的约束

  • 未连接不显示预览、不显示会话，快门不可按。
  • 不可用能力降级为禁用态，原因写在快门上方的状态行。
  • 机身身份、网络、契约门禁、诊断全部在设置页。
